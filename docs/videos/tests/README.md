# 测试视频：检测前后

以下 3 组视频使用本地模型 `checkpoints/fireguard_s_local_v1/final/best.pt`，检测类别为 fire 和 smoke。

| 视频 | 检测前 | 检测后 | 时长 | 推理 imgsz |
| --- | --- | --- | --- | --- |
| demo_3 | [查看原视频](demo_3_before.mp4) | [查看检测结果](demo_3_after.mp4) | 42.44 秒 | 768 |
| demo_4 | [查看原视频](demo_4_before.mp4) | [查看检测结果](demo_4_after.mp4) | 67.73 秒 | 768 |
| demo_5 | [查看原视频](demo_5_before.mp4) | [查看检测结果及实时速度](demo_5_after.mp4) | 15.35 秒 | 960 |

检测参数：置信度阈值 `0.25`，IoU 阈值 `0.30`，同类别包含框去重阈值 `0.90`。demo_5 的实时速度显示为处理 FPS，采用最近 30 帧时间间隔滚动计算。

上传版本为完整时长的 1280×720 H.264 MP4，经过压缩以便浏览和下载。720p 是展示视频分辨率；模型实际推理输入参数见表格。检测框和已有速度叠加来自先前生成的结果，本次上传没有重新推理或重新训练。

如 GitHub 未显示播放器，可点击视频文件页面的 Raw / Download，或下载仓库后本地播放。
